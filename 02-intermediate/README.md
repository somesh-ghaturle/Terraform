# Terraform Intermediate

Welcome to the intermediate Terraform module! Build upon the basics and learn more advanced concepts.

## 📖 What You'll Learn

- Creating reusable modules
- Managing Terraform state
- Using provisioners
- Working with data sources
- Managing multiple environments with workspaces

## 📚 Modules

1. **[Modules](./01-modules/)** - Creating and using reusable Terraform modules
2. **[State Management](./02-state-management/)** - Understanding and managing Terraform state
3. **[Provisioners](./03-provisioners/)** - Running scripts and commands during resource creation
4. **[Data Sources](./04-data-sources/)** - Fetching information from existing infrastructure
5. **[Workspaces](./05-workspaces/)** - Managing multiple environments

## ⏱️ Estimated Time

Completing this module should take approximately 8-10 hours.

## 🎯 Prerequisites

- Completed the [Basics](../01-basics/) module
- Understanding of Terraform workflow and commands
- Familiarity with variables and outputs

## 🚀 Getting Started

Start with module 1: [Modules](./01-modules/)
